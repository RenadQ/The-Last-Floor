## 📱 Project Overview
**The Last Floor** is a short psychological horror mobile game prototype developed using **React Native with Expo Go**.  
The game takes place inside a malfunctioning elevator trapped between floors in an abandoned building. Each floor introduces subtle environmental changes and narrative clues that challenge the player’s observation and decision-making skills.

Unlike traditional mobile horror games, this project focuses on **atmospheric and psychological tension** rather than jump scares or combat mechanics.

---

## 🎯 Problem Statement
Most mobile horror games rely heavily on jump scares or complex controls that are not suitable for touch-based devices.  
This project addresses this issue by providing a minimalistic, immersive horror experience that emphasizes atmosphere, sound design, and player perception.

---

## 👥 Target Audience
Mobile users who enjoy short psychological horror experiences and atmospheric storytelling games.

---

## ⭐ Core Features
- Main menu with start and settings options  
- Central elevator hub for navigation  
- Five interactive floors with unique designs  
- Psychological horror elements without jump scares  
- Dynamic ambient sound effects  
- Lighting and visual effects to increase tension  
- Simple touch-based movement and interaction  
- Puzzle-based gameplay on the final floor  
- Multiple endings based on player decisions  
- Haptic feedback and screen effects for immersion  

---

## 🛠️ Technologies Used
- **React Native**
- **Expo Go**
- **expo-av** (audio and sound effects)
- **expo-haptics** (vibration feedback)
- **expo-sensors** (optional device interactions)
- **Animated API** (lighting and visual transitions)
